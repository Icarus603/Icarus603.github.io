Tech Innovation Eval Agent: Corporate Innovation Assessment2025.12
  • Data pipeline: Aligned balance sheets, income statements, cash flow statements, listing information and patent data under a unified firm identifier, yielding about 2,000 firm-level samples.
  • Weak supervision: With no ground-truth innovation score, built 58 indicators across three dimensions (R&D, operations, support) and generated soft labels from percentile-rank scores weighted by the entropy weight method.
  • Modeling: Combined financial indicators, patent technology-evolution features and BGE text embeddings; compared six models (CatBoost, XGBoost, LightGBM, ElasticNet, Lasso, MLP) with an 80/20 split, 5-fold cross-validation and ablation over three feature groups. CatBoost performed best, and patent-technology and operating features contributed most.
  • Agent: A LangGraph ReAct agent with tools to score a firm, generate reports and run the pipeline, returning SHAP-based attributions; a Streamlit chat UI shows its reasoning and tool calls, and long-running jobs require confirmation.
